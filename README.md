## Folder Structure
Each practical is organized in its own folder from `practical-1` to `practical-11`:

## List of Practicals

| Practical | Topic Covered |
| :--- | :--- |
| **Practical 1** | Basic Java syntax, Enums, and Switch expressions |
| **Practical 2** | Classes, Objects, Constructors, and Encapsulation |
| **Practical 3** | Object methods (`toString`, `equals`, `hashCode`) and Nested classes |
| **Practical 4** | Strings, StringBuilder, and Regex validation |
| **Practical 5** | Inheritance, Abstract classes, and Polymorphism |
| **Practical 6** | Interfaces, Default methods, and Lambdas |

| **Practical 8** | Exception handling (`try`, `catch`, `finally`, custom exceptions) |

| **Practical 10** | Thread pools and Inter-thread communication (`wait`, `notify`) |
| **Practical 11** | File handling (NIO) and Object Serialization |

## How to Run Any Program

1. Open your terminal or command prompt inside the task folder.
2. Compile the Java file:
   ```bash
   javac FileName.java
   ```
3. Run the compiled program:
   ```bash
   java FileName
   ```
